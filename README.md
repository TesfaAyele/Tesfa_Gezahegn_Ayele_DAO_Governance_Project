Hello, everyone. My name is Tesfa, I am 17 years old, and this is my first ever Web3 Blockchain Project. I decided to build a DAO Governance Smart Contract. 

I want to build an optimistic voting system where people/ wallets possessing a custom GovernanceToken can participate in. A single "guardian" can veto the proposal
if deemed necessary, and people with more than 10% of the token can veto it as well. After the challenge period is over, normal participants can 
question the proposal. If no one questions the proposal, then it will automatically pass.
There're functions in the contract such as delegate (), execute (), propose (), etc. that grants each role their adjacent power.
